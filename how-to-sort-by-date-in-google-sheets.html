How to Sort by Date in Google Sheets

Sorting by date works almost exactly like sorting alphabetically or numerically in Google Sheets — with one important exception that trips up a lot of people, covered further down. Here are the three ways to do it, from quickest to most flexible.

Method 1: Sort Sheet by Column (Fastest)

Best when your date column is the only thing you need to sort by, across the whole sheet.

  1. Click the column letter at the top of your date column to select it.
  2. Click the small arrow that appears in the column header.
  3. Choose Sort sheet A → Z (oldest to newest) or Sort sheet Z → A (newest to oldest).
This rearranges every row in the entire sheet based on the date column — not just the column itself — so the rest of your data stays correctly matched to each date.

Method 2: Sort Range with Multiple Columns

Use this when you want more control, like sorting by date first and then by another column.

  1. Select the range of cells you want to sort, including the date column.
  2. Go to Data → Sort range → Advanced range sorting options.
  3. Check Data has header row if your columns have titles.
  4. Choose the date column and select A → Z (oldest to newest) or Z → A (newest to oldest).
  5. Optional: click Add another sort column to break ties with a second field.
  6. Click Sort.

Method 3: The SORT Function (Doesn't Touch Original Data)

If you want a sorted view without rearranging your source data, use a formula instead:

=SORT(A2:C, 1, TRUE)

This sorts the range A2:C by its first column (the date column, assuming it's column A), in ascending order. Change TRUE to FALSE for descending order. The result updates automatically if the original data changes.

The Most Common Problem: Dates Sorting Like Text

If your dates end up sorting alphabetically instead of chronologically — for example, "1/2/2026" appearing before "12/1/2025" — the column almost certainly contains text that looks like a date rather than an actual date value.

  1. Select the date column.
  2. Go to Format → Number → Date.

If reformatting alone doesn't fix it, the values may have been entered or imported as plain text. Convert them with:

=DATEVALUE(A2)

Dragged down the column, this converts each text entry into a real date value that sorts correctly.

Frequently Asked Questions

Why won't my dates sort correctly in Google Sheets?

This almost always means the dates are stored as text rather than actual date values. Reformatting the column as a date, or using DATEVALUE to convert text into real dates, fixes it.

Does sorting by date change the original data?

Using Sort sheet or Sort range rearranges the rows in place, changing the original data. The SORT function instead creates a separate, dynamically updated copy without touching the source range.

Can I sort by date and then by another column?

Yes. Advanced range sorting options lets you add a second sort column, so rows with the same date can be further sorted by another field, like name or category.
